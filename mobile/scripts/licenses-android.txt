墨页 Android 版附带的第三方组件
==============================

除 app/ 目录中已有的组件（见 THIRD_PARTY_NOTICES.md）外，安卓版 APK 还包含：

- Capacitor 8.6.2（@capacitor/android；@capacitor/core 的 vendor/capacitor.js）、@capacitor/app 8.1.2、@capacitor/filesystem 8.1.5、
  @capacitor/share 8.0.3 —— MIT 许可，Copyright (c) 2017-present Drifty Co. https://github.com/ionic-team/capacitor
- ionfilesystem-android 1.1.1（@capacitor/filesystem 使用）—— MIT 许可，Copyright (c) 2025 Ionic
  https://github.com/ionic-team/ion-android-filesystem
- AndroidX（appcompat、core、core-splashscreen、activity、fragment、coordinatorlayout、webkit 等）——
  Apache License 2.0，The Android Open Source Project
- Apache Cordova Android framework 14.0.1（Capacitor 的兼容层）—— Apache License 2.0，The Apache Software Foundation
- Kotlin 标准库、kotlinx.coroutines —— Apache License 2.0，JetBrains s.r.o.
- PDF.js 5.6.205 的 legacy 构建（代替 app/ 里的同版本 modern 构建，兼容较旧的 WebView）—— Apache License 2.0

Apache License 2.0 全文见同一目录下的 vendor/PDFJS-LICENSE.txt。
