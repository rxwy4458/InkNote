# 墨页安卓版：构建说明

安卓版和 Windows 版运行**同一套** `app/` 代码，外面套了一层 [Capacitor](https://capacitorjs.com/) 8 的安卓外壳。手机上的笔记保存在墨页自己的应用数据里，不联网，也不申请联网权限。

- 支持 Android 7.0 及以上的手机和平板；需要「Android System WebView」111 或更新的版本（太旧时，墨页会显示一页更新说明）。
- 应用 ID `com.inknote.app`，版本 0.7.0（versionCode 700）。

## 这个文件夹里有什么

| 路径 | 作用 |
| --- | --- |
| `scripts/build-web.mjs` | 把 `../app` 复制成 `www/`：换成适合手机的视口、使用同版本 PDF.js 的 legacy 构建（兼容较旧的 WebView）、内置插件放到 `builtin-plugins/`（Capacitor 会清空 `plugins/` 这个名字的文件夹） |
| `capacitor.config.json` | 外壳设置：`https://localhost` 本地页面、最低 WebView 版本、全面屏（edge to edge）边距由页面自己处理 |
| `android/` | Android Studio / Gradle 工程。签名、图标、启动画面、权限都在这里 |
| `scripts/make-icons.mjs` | 由 `app/icon.svg` 生成启动器图标（自适应图标 + Android 13 主题图标） |
| `scripts/emulator-run.sh`、`tests/emulator.mjs` | 云端构建时在安卓模拟器上自动检查（书写、捏合缩放、导出 PDF、返回键、插件） |
| `../.github/workflows/android.yml` | GitHub Actions 云端构建：出 APK、签名、模拟器检查、发布到 Releases |

## 签名密钥（一定要保存好）

APK 用 `inknote-release.jks` 签名。**以后每个新版本都必须用同一个密钥签名**，手机才能直接覆盖安装；换了密钥，只能先卸载旧版再装，而卸载会删除手机上的笔记。

密钥和密码在单独的压缩包「墨页安卓签名密钥」里，请存到安全的地方（网盘、U 盘各一份），不要上传到公开的地方。

## 方法一：让 Claude 构建（最省事）

在 claude.ai 的「设置 → 连接器」里连接 GitHub，然后告诉 Claude「继续打包安卓」。Claude 会建一个私有仓库，配置好签名密钥，用 GitHub 的云端机器构建，在模拟器上检查后把 APK 发给你。

## 方法二：自己用 GitHub 云端构建

1. 在 GitHub 新建一个**私有**仓库（Private）。
2. 用 [GitHub Desktop](https://desktop.github.com/) 把整个墨页源代码文件夹（包含 `app/`、`mobile/`、`.github/`）提交并推送到这个仓库。
3. 仓库页面 → Settings → Secrets and variables → Actions → New repository secret，按「墨页安卓签名密钥」里的 `密钥信息.txt` 添加四项：
   - `INKNOTE_KEYSTORE_B64`：`INKNOTE_KEYSTORE_B64.txt` 的全部内容
   - `INKNOTE_KEYSTORE_PASSWORD`、`INKNOTE_KEY_PASSWORD`：密码
   - `INKNOTE_KEY_ALIAS`：`inknote`
4. 仓库页面 → Actions → 「Android APK」 → Run workflow。大约 20–30 分钟后，在仓库的 Releases 里下载 `InkNote-Android-0.7.0.apk`。以后推送新的代码会自动重新构建。

## 方法三：在 Windows 上用 Android Studio 构建

不需要 Node.js：页面文件和 Capacitor 的安卓代码已经放在压缩包里。

1. 安装 [Android Studio](https://developer.android.google.cn/studio)（国内可用这个地址），第一次打开时按提示装好 Android SDK。
2. 把 `inknote-release.jks` 和 `keystore.properties`（都在「墨页安卓签名密钥」里）复制到 `mobile\android\` 文件夹。
3. Android Studio → Open → 选 `mobile\android` 文件夹，等底部的 Gradle 同步完成（第一次要下载不少文件）。
4. 打开 Android Studio 底部的 Terminal，运行：

   ```
   gradlew.bat assembleRelease
   ```

5. APK 在 `mobile\android\app\build\outputs\apk\release\app-release.apk`。

## 改了 `app/` 里的代码以后

需要 Node.js 22 或更新的版本：

```sh
cd mobile
npm ci
npm run sync        # 重新生成 www/ 并复制进 android/
```

然后按上面任一方法构建。`npm run check` 可以检查 `www/` 是否和 `app/` 一致。

## 安装到手机

把 APK 传到手机（数据线、微信文件传输、网盘都可以），点开安装。第一次安装时，系统会要求允许「安装未知应用」（这个 APK 不是从应用商店下载的）。之后的新版本直接覆盖安装，笔记都在。

## 与 Windows 版的区别

- 手指操作：一指书写（开启「仅用笔书写」后一指滚动）、两指滚动和捏合缩放、两指轻点撤销；第一次用触控笔时自动开启「仅用笔书写」，防止手掌误触。
- 导出的 PDF、`.inknote` 备份和全部笔记的 `.zip` 保存在手机的「文档 › 墨页」文件夹，也可以直接发送到其他应用。
- 「笔记库文件夹」、分屏、Calibre 格式转换只在 Windows 版里有；安卓版用「导入导出」在两台设备之间搬笔记。
- 插件只能用 `.inkplugin` 文件安装。
