# 墨页插件开发指南

插件接口版本：**1**（`apiVersion: 1`）　适用于：墨页 InkNote 0.7.0 及以后

墨页是一个 Windows 笔记软件（Electron 桌面程序，界面是网页技术）。墨页本身只是一个**载体**：
笔记库、保存、页面编辑器（笔、荧光笔、橡皮擦、套索、文字框、撤销、缩放、导出 PDF）、帖子页面都是墨页提供的公共服务；
**能新建什么、能打开什么，全部由插件决定**。时间画布、普通画布、二维模板画布、发帖子、导入阅读都是插件。

这份文档是写给开发插件的人（或 AI）的完整约定。只要遵守它，新模块就能直接装进墨页，不需要改动墨页本身。

---

## 0. 给 AI 的说明（请先读）

如果你是收到这份文档的 AI：用户会用中文描述一个新模块的需求。请按下面的规则交付：

1. **只交付一个插件文件夹**：`<插件id>/plugin.json` + `<插件id>/index.mjs`，需要时再加 `.mjs`、`.css`、`.svg` 文件。不要修改、不要假设墨页的任何内部文件。
2. **只使用 `activate(host)` 收到的 `host` 对象**（第 4 节）。不要 `import` 墨页自己的模块（比如 `../../app.mjs`），这些文件随版本变化，插件会坏掉。
3. **纯浏览器 ES 模块**：不需要也不能使用构建工具、npm 包、Node.js、`require`、文件系统、网络请求（页面的安全策略禁止加载外部网址，`eval` 也被禁止）。所有代码和资源都放在插件文件夹里，用相对路径互相引用。
4. **界面用中文**，风格跟随墨页（第 6 节的颜色变量和图标）。
5. **数据必须是普通 JSON**，按第 5 节存放，并写导入检查函数。
6. 交付时附上：安装方法（第 8 节）、自测步骤（第 9 节逐条对照）、以及你用到了哪些 host 接口。
7. 不确定某个接口是否存在时，**以本文档和 `plugin-api.d.ts` 为准**，不要臆造接口。

## 1. 插件长什么样

```
my-plugin/              ← 文件夹名必须等于 plugin.json 里的 id
  plugin.json           ← 必需：插件说明
  index.mjs             ← 必需：入口模块，导出 activate(host)
  style.css             ← 可选：用 host.ui.addStyle('style.css') 加载
  icon.svg              ← 可选：自己的图标（单色，用 currentColor 或纯黑路径）
  其他 .mjs             ← 可选：用相对路径 import './其他.mjs'
```

### plugin.json

```json
{
  "id": "cornell-canvas",
  "name": "康奈尔笔记画布",
  "version": "1.0.0",
  "apiVersion": 1,
  "main": "index.mjs",
  "icon": "cornell.svg",
  "author": "你的名字",
  "description": "一句话说明这个插件做什么（会显示在插件管理里）。",
  "documents": [{ "kind": "notebook", "canvasType": "cornell" }],
  "fileTypes": [],
  "minAppVersion": "0.7.0"
}
```

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| `id` | 是 | 小写字母、数字、连字符，2–41 个字符。全局唯一，也是文件夹名。和内置插件同 id 时，你的插件会**覆盖**内置版本（用来改进内置模块）。 |
| `name` | 是 | 显示名称，≤ 40 字。 |
| `version` | 是 | `主.次.修订`，如 `1.0.0`。 |
| `apiVersion` | 是 | 固定写 `1`。 |
| `main` | 否 | 入口文件，默认 `index.mjs`。 |
| `icon` | 否 | 墨页图标名（第 6 节列表）或插件里的 `.svg` 文件名。 |
| `description` | 否 | ≤ 300 字。 |
| `documents` | **建议** | 这个插件负责打开哪些笔记：`{kind, canvasType?}` 的数组。插件停用后，墨页靠它知道“这本笔记需要哪个插件”，并提示用户重新启用。 |
| `fileTypes` | 否 | 能导入的文件扩展名（只是说明，用于提示“需要启用某插件”）。真正的导入用 `host.importers.register`。 |
| `minAppVersion` | 否 | 需要的最低墨页版本。 |

### index.mjs

```js
export function activate(host) {
  // 在这里登记入口、文档类型、画布类型、导入器……
}
export function deactivate() {
  // 可选：插件被停用时调用。登记过的入口会被墨页自动移除，这里只需清理你自己加的东西（定时器、全局事件等）。
}
```

## 2. 生命周期

- **启动**：墨页启动时先读取内置插件（程序目录 `app/plugins/`），再读取用户安装的插件（`%APPDATA%\InkNote\plugins\`），对每个启用的插件调用一次 `activate(host)`。分屏右侧是另一个独立页面，也会各自加载一次。
- **启用 / 停用**：用户在「设置 → 插件」里开关。停用时调用 `deactivate()`，并**自动撤销**这个插件登记的所有入口；如果正在打开它的笔记，会先回到笔记库。用它创建的笔记保留在库里，卡片上标注“需要「插件名」插件”。
- **卸载**：用户安装的插件会被删除；内置插件可以卸载（隐藏）并随时重新安装。
- **出错**：`activate` 抛出错误时，插件被标记为“启动失败”，错误信息显示在插件管理里，墨页其余部分照常工作。
- **更新**：覆盖插件文件夹后回到墨页，墨页会重新扫描并重新加载 `plugin.json` 和入口文件；如果改动了入口以外的模块文件，重启墨页才能完全生效。

## 3. 插件能做的四类事

| 想做的事 | 用什么 | 例子 |
| --- | --- | --- |
| 在笔记库加入口 | `host.library.addTile / addCategory / addNewMenuItem` | 首页磁贴、左侧分类、「新建」菜单 |
| 认领一种笔记 | `host.docTypes.register` | 卡片上的类型名、图标、预览图 |
| **做一种新画布** | `host.notebook.registerCanvasType` | 时间画布、二维模板画布、康奈尔笔记 |
| 导入一种文件 | `host.importers.register` | PDF、EPUB |

**新画布是最常见的插件**：页面编辑器的全部功能（笔、荧光笔、两种橡皮擦、套索复制粘贴、带格式文字框和公式、批注、撤销重做、缩放、分页、导出 PDF、备份）自动可用，插件只负责“这种画布的页面有什么不同”。

## 4. host 接口（版本 1）

完整的类型定义见同目录的 `plugin-api.d.ts`。

### 4.1 `host.plugin`

```js
host.plugin.id          // 插件 id
host.plugin.version     // 插件版本
host.plugin.baseUrl     // 插件文件夹的网址（以 / 结尾）
host.plugin.url('a.png')// 插件文件夹里某个文件的完整网址
host.apiVersion         // 1
host.appVersion         // 墨页版本，如 "0.7.0"
```

### 4.2 `host.library`：笔记库入口

```js
host.library.addTile({ id, title, subtitle, icon, className?, order?, run })
// 首页“快捷新建”磁贴。title ≤ 20 字，subtitle ≤ 30 字。order 越小越靠前（内置：10 时间画布、20 普通画布、30 二维模板、40 发帖子、50 导入阅读）。

host.library.addCategory({ id, title, icon, order?, match(doc) → boolean, newCard?: { title, subtitle, icon?, run } })
// 左侧“分类”里的一项。match 决定哪些笔记属于这个分类；newCard 是分类页里第一张“新建”卡片。

host.library.addNewMenuItem({ id, title, subtitle, icon, tone?, order?, run })
// 左上角「新建」按钮弹出的菜单项。tone：'primary' | 'secondary' | 'tertiary' | 'neutral'。

host.library.refresh()  // 你的数据变了，需要重新画笔记库时调用
```

`run()` 可以是异步函数，抛出的错误会显示为提示条。

### 4.3 `host.docTypes`：认领笔记

```js
host.docTypes.register({
  id, label, icon, iconClass?,   // iconClass 决定类型图标底色；不写就是中性色
  match(doc) → boolean,          // 哪些笔记归你（和 plugin.json 的 documents 保持一致）
  preview?(doc) → string,        // 笔记卡片上的预览 HTML（自己转义用户文字：host.ui.escape）
  amount?(doc) → string,         // 卡片上的“几页”说明，如 "3 页 · 5 个模板"
  searchText?(doc) → string,     // 额外参与笔记库搜索的文字
})
```

没有任何插件认领的笔记打不开，会提示“需要插件”。

### 4.4 `host.notebook`：页面编辑器与画布类型

```js
host.notebook.registerCanvasType({
  id,                    // 画布类型，存进笔记的 canvasType，例如 'cornell'
  title, subtitle, icon, order?,
  paperModes?,           // ['infinite','paged'] 的子集。只写 ['paged'] 表示只能 A4 分页
  defaultTemplate?,      // 'blank' | 'ruled' | 'grid' | 'dot'
  initPage?(page),       // 每新建一页（新建笔记、添加页面）时调用，可以给 page 加普通字段
  addPageHint?, createdToast?,
  page?: { ...页面扩展，见下 }
})

host.notebook.newDialog({ canvasType })   // 打开墨页标准的“新建画布”对话框（名称、文件夹、纸张、线距、封面）
await host.notebook.create({ canvasType, title?, folder?, template?, mode?, spacing?, color? }) // 不弹窗直接创建，返回笔记
```

“新建画布”对话框会列出所有已登记的画布类型，用户可以在里面切换。

#### 页面扩展（page extension）

画布类型可以给每一页存自己的数据：`page.ext[key]`。墨页在固定的时机调用这些函数（都可选，`key/init/validate` 必需）：

| 函数 | 什么时候调用 | 用途 |
| --- | --- | --- |
| `key` | — | 数据存在 `page.ext[key]`，建议用画布类型 id |
| `init(page)` | 新建一页时 | 写入初始数据 `page.ext[key] = {...}` |
| `validate(raw, util)` | 导入备份时 | 检查 `raw`（来自文件，不可信），**返回**干净的数据，不合格就 `throw`。笔迹用 `util.annotation(a)` 检查 |
| `decorate(ctx, page)` | 画纸张时（编辑器、缩略图、连续滚动的页面、导出 PDF） | 在纸上画固定装饰（分区线、格子、底纹）。ctx 已是页面坐标 |
| `underlay(ctx, page, size)` | 编辑器每次重画笔迹时 | 在“可编辑笔迹”下面画只读内容（比如锁定的图层）。只在编辑器里；`size` 是画布像素尺寸 |
| `displayAnnotations(page)` | 画缩略图、连续滚动的页面、导出 PDF 时 | 返回这一页“看起来”的全部笔迹（默认就是 `page.annotations`） |
| `searchText(page)` | 笔记库搜索时 | 返回文字数组 |
| `mount()` | 编辑器打开你的笔记时 | 往 `host.editor.stage()` 里加你的界面（工具条、侧栏） |
| `pageShown(page)` | 每次显示一页（翻页、撤销、缩放后） | 根据这一页的数据刷新界面 |
| `changed(page)` | 每次可撤销的修改之后（画一笔、擦除、你的命令） | 刷新缩略图等 |
| `unmount()` | 离开编辑器时 | 移除你的界面和事件 |

**最重要的一条约定**：编辑器的所有工具只读写 `page.annotations`。想让工具作用在“你的某部分数据”上，就把那部分数据放进 `page.annotations`，其余放在 `page.ext[key]`，切换时把数组换进换出（二维模板画布就是这样实现“只擦当前图层”的）。

**撤销**：墨页的撤销记录会同时保存 `page.annotations` 和 `page.ext`。你的命令按这个模式写，就能 Ctrl Z：

```js
const before = host.editor.snapshot();
// …修改 page.annotations 或 page.ext[key]…
host.editor.commit(before);   // 记入撤销、保存、刷新缩略图，并调用 changed()
```

只是“切换显示”（不算修改）时，用 `host.editor.save(false)` 保存即可，不进撤销记录。

### 4.5 `host.editor`：正在打开的页面编辑器

只在页面编辑器打开时有意义（否则返回 `null`）。

```js
host.editor.doc() / page() / pageIndex()   // 当前笔记、当前页、页码（从 0 开始）
host.editor.stage()        // 画布区域的容器元素，往里面加 position:absolute 的界面
host.editor.redraw()       // 重画笔迹层（会调用你的 underlay）
host.editor.snapshot()     // 取撤销快照
host.editor.commit(before) // 记入撤销 + 保存 + 刷新
host.editor.save(touch)    // 保存当前笔记；touch=true 会更新“最近编辑”时间
host.editor.refreshThumbnail()
host.editor.zoom()         // 当前缩放比例
host.editor.inkSize()      // 笔迹画布的像素尺寸 {width,height}
host.editor.finishText()   // 结束正在编辑的文字框（切换前调用）
host.editor.clearSelection()
host.editor.dock()         // 书写工具栏位置：'bottom'|'top'|'left'|'right'
```

### 4.6 `host.importers`：导入文件

```js
host.importers.register({ id, label, extensions: ['abc'], async import(file) { …; return docId; } })
host.importers.pick()   // 打开系统的选择文件窗口（等同于点“导入”）
```

用户把文件拖进窗口或点“导入”时，墨页按扩展名找到你的导入器。`import` 里用 `host.docs.create(doc)` 建笔记并返回它的 id，墨页会打开它。

### 4.7 `host.docs`：笔记数据

```js
host.docs.all()                 // 全部笔记（数组，请当作只读）
host.docs.get(id)
await host.docs.create(doc)     // 新建并保存，返回笔记；需要 title 和至少一页 pages
await host.docs.save(doc, { touch: true })
await host.docs.open(id)        // 打开笔记
host.docs.uid()                 // 生成新的 id
```

### 4.8 `host.services`：墨页内置服务

```js
await host.services.importPdf(file)    // 用墨页的 PDF 阅读服务导入，返回笔记 id
await host.services.importEbook(file)  // 导入电子书
host.services.newPost()                // 打开“新建帖子”
```

### 4.9 `host.ink`：笔迹绘制

```js
host.ink.drawAnnotation(ctx, a)   // 画一条批注（任何类型）
host.ink.bounds(a)                // {x,y,w,h}
host.ink.hitAnnotation(a, point, radius)
host.ink.PAPER                    // A4：{width:595.28, height:841.89}
host.ink.COLORS / host.ink.MARKERS
await host.ink.prepareRich(list, scale)  // 画带格式文字框前先准备（异步）
```

### 4.10 `host.ui`：界面工具

```js
host.ui.icon(name)                      // 图标 HTML（墨页图标名，或插件里的 .svg）
host.ui.escape(text)                    // 转义成安全的 HTML 文本
host.ui.toast(message, isError?)        // 底部提示条
host.ui.dialog(title, html, { subtitle?, submit?(formData) })  // 墨页风格对话框
host.ui.close()                         // 关闭对话框
host.ui.actions(okText?, danger?)       // 对话框底部的“取消/确定”按钮 HTML
await host.ui.ask(title, label, value?) // 输入一行文字，取消返回 null
host.ui.menu(title, [{ label, sub?, icon?, danger?, disabled?, run }, { separator: true }], { subtitle? })
host.ui.addStyle('style.css')           // 加载插件里的样式表（停用插件时自动移除）
host.ui.run(async () => {…})            // 运行并把错误显示成提示条
```

## 5. 数据约定

### 5.1 笔记（doc）

```js
{
  id: "uuid", title: "名称",
  kind: "notebook",            // 画布类插件都用 notebook；其他：pdf、ebook、discussion
  canvasType: "cornell",       // 你的画布类型 id
  color: "olive",              // 封面色：olive | sand | blue | pink
  folder: "",                  // 所在文件夹名，"" 表示未分类
  favorite: false,
  createdAt: 1700000000000, updatedAt: 1700000000000, lastPage: 0,
  pages: [ 页, … ]
}
```

### 5.2 页（page）

```js
{
  id: "uuid", width: 595.28, height: 841.89,   // A4，单位是 PDF 点
  infinite: false,                              // true 表示无限画布（尺寸会增长）
  sourceIndex: null,                            // 画布页一律是 null（PDF 页才有数字）
  template: "blank",                            // blank | ruled | grid | dot
  spacing: "standard", margin: false,
  title: "",                                    // 页面标题
  annotations: [ 批注, … ],                     // 编辑器工具读写的地方
  comments: [],                                 // 批注讨论（墨页管理）
  ext: { cornell: { v: 1, … } }                 // 插件自己的数据
}
```

### 5.3 批注（annotation）

| type | 字段 |
| --- | --- |
| `pen` / `marker` | `id, color, width, pressure, points:[{x,y,p}]`（p 是 0–1 的笔压） |
| `rect` | `id, color, width, x, y, w, h` |
| `text` | `id, color, text, x, y, size, w?, h?` |
| `rich` | `id, color, x, y, w, h?, size, html, plain`（带格式文字框；`html` 由墨页清理） |

坐标都是页面坐标（左上角为 0,0）。颜色是 `#rrggbb`。

### 5.4 规则

1. `page.ext[key]` 里只放普通 JSON：对象、数组、字符串、数字、布尔。不要放函数、DOM、Map、Date。
2. 数据里放一个版本号（如 `v: 1`）。以后改格式时，新版本的插件要能读旧数据。
3. `validate` 必须把来自文件的数据当作不可信：检查类型、范围、数量上限，返回新的干净对象。笔迹一律交给 `util.annotation(a)`。
4. 数据总量要合理：单页插件数据不要超过几 MB。
5. 不要改别的插件或墨页的字段含义；需要新字段就放进你自己的 `page.ext[key]`。
6. 插件停用期间，墨页会原样保留 `page.ext[key]`，备份和导入也会带上它。
7. 笔记会原样写进 `.inknote` 文件（单本备份，以及用户设置的「笔记库文件夹」），`page.ext` 也在里面。另一台电脑读这些文件时同样经过你的 `validate`，所以格式要稳定、能向前兼容。

## 6. 界面约定

- **放在哪里**：自己的界面放进 `host.editor.stage()`，用 `position:absolute`。右上角是页码与缩放条（`.page-controls`），工具栏默认在底部；`.stage[data-dock="top|left|right"]` 表示用户把工具栏挪到了别处，请用这个属性避开它。
- **颜色**：用墨页的主题变量，深色模式自动适配：
  `--md-primary`、`--md-on-primary`、`--md-primary-container`、`--md-on-primary-container`、`--md-secondary-container`、`--md-on-secondary-container`、`--md-surface-container-lowest/low/high/highest`、`--md-on-surface`、`--md-on-surface-variant`、`--md-outline`、`--md-outline-variant`、`--md-error`；阴影 `--e1`…`--e3`；动画曲线 `--spring`。纸张始终是白色。
- **图标**：`host.ui.icon(名字)`。可用名字：
  `comment post book reading grid list clock time star folder plus upload search chevron left down more more-v arrow pen draw edit marker eraser text rect lasso hand undo redo download check check-circle close trash bookmark pages minus fit help settings gear shield storage leaf spark rotate file info calendar date-add image reply home library palette send dark light auto colorize save error new-note sync split swap copy paste cut up down-arrow title gesture select-all spacing margin page-setup duplicate drag dock continuous single-page cloud cloud-done cloud-sync cloud-off login logout layers lock unlock fork merge-down templates plugin folder-open code refresh install menu share pinch touch`。
  需要别的图标就在插件里放一个 `.svg`（单色），`icon` 写文件名。
- **文字**：中文；按钮要有 `title` 提示；能用键盘操作。
- **类名**：自己的 CSS 类加前缀（例如 `cornell-…`），避免和墨页冲突。
- **触屏与安卓版**：墨页也有安卓版（手机、平板），插件不用改就能在上面运行。界面请用 Pointer Events（`pointerdown` / `pointermove` / `pointerup`），不要只靠鼠标悬停和右键菜单（触屏上没有）；能点的东西至少 40×40 像素，可以用 `@media (pointer:coarse)` 在触屏上放大；「双击」在触屏上请自己判断两次轻点（参考二维模板插件的 `doubleTap`）。页面上的手指手势（一指书写或滚动、两指滚动和捏合缩放、两指轻点撤销）由墨页处理，插件不要在 `.canvas-workspace` 上拦截触摸。

---

## 7. 安全与限制

- 插件和墨页运行在同一个页面里，能读到所有笔记。只安装你信任的插件。
- 不能联网、不能加载外部脚本或字体、不能用 `eval`；不能访问电脑上的文件（只能通过 host 接口）。
- 插件出错不会让墨页崩溃，但可能让它负责的笔记打不开；请在 `validate`、`decorate`、`underlay` 里避免抛出意外错误。

---

## 8. 安装与分发

**方法一（最简单）**：「设置 → 插件 → 打开插件文件夹」，把整个插件文件夹复制进去，切回墨页窗口，墨页会自动扫描并启用。

**方法二**：把插件文件夹的内容打成 zip（`plugin.json` 在 zip 根目录，或在唯一的一层文件夹里），扩展名改为 `.inkplugin`，在「设置 → 插件 → 从文件安装插件…」里选择它。

**方法三**：「从文件夹安装插件…」，直接选插件文件夹。

**安卓版**只能用方法二：把 `.inkplugin` 文件传到手机上，在「设置 → 插件 → 从文件安装插件…」里选它。插件保存在墨页自己的应用数据里，卸载墨页时会一起删除。

和内置插件同 id 的插件会覆盖内置版本；卸载它就恢复内置版本。

## 9. 自测清单

交付前逐条确认：

1. `plugin.json` 的 `id` 和文件夹名一致，`apiVersion` 是 1，`documents` 写对了。
2. 安装后插件管理里显示正常，没有“启动失败”。
3. 首页磁贴、左侧分类、「新建」菜单里的入口都能用。
4. 新建一本笔记：书写、擦除、撤销、重做、添加页面、缩放都正常；你的界面没有挡住工具栏和页码条（试试把工具栏拖到顶部、左侧、右侧）。
5. 关闭再打开笔记，数据都在；重启墨页后也在。
6. 「导出可编辑备份」后再导入：内容一致（`validate` 正常）。故意改坏备份里的 `ext` 数据，导入应提示错误而不是让墨页出问题。
7. 导出 PDF、页面缩略图显示正确（需要时实现 `displayAnnotations` 或 `decorate`）。
8. 在插件管理里停用插件：入口消失，笔记还在并提示“需要插件”；重新启用后能正常打开。
9. 深色模式下界面可读。
10. 有条件的话，在浏览器开发者工具的手机模拟（设备工具栏）里或安卓版里试一下：手指点按你的按钮正常，两指缩放、滚动页面不受影响。
11. 浏览器开发者工具里没有报错（墨页桌面版按 Ctrl Shift I 不可用时，可以用 `npm run dev` 在浏览器里调试，见第 10 节）。
