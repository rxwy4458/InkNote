墨页 InkNote 0.7.0 · Windows 离线包

安装：解压压缩包后，双击 InkNote-Setup-0.7.0-offline.exe。
安装向导里可以选安装位置（默认在 %LOCALAPPDATA%\Programs\InkNoteDesktop，可以换到 D 盘等），以及是否创建桌面、开始菜单快捷方式，是否装完就打开。
包内包含完整运行组件，安装无需联网。笔记数据保存在 %APPDATA%\InkNote，和安装位置无关。
从 0.3.x – 0.6.1 升级：直接运行新安装器，原有笔记会自动出现。

卸载：先保存并关闭墨页，再双击安装位置里的 Uninstall-InkNote.exe（压缩包里也附了一份）。
也可以在 Windows 设置 → 应用 → 已安装的应用 → 墨页 InkNote 中卸载。
笔记数据库、图片、电子书、笔记备份、插件和笔记库文件夹都会保留。卸载也不需要联网。

0.7.0 的变化：
· 二维模板画布（新建 → 二维模板画布）：
  - 左上方横条是一排平行模板：单击切换；按住后左右滑动，画面跟着切换，松手即停。“+”新建空白模板，“⎘”克隆分叉：复制当前模板的全部锁定层，在右边生成一个新模板，只改不一样的部分。
  - 右侧竖条是当前模板的图层：单击选中（蓝框）；双击锁定或解锁（金框 🔒）；按住后上下滑动快速翻看草稿。“+”新建图层，“↓”把当前草稿层合并到上方的锁定层。
  - 锁定层常驻显示，橡皮擦擦不到；笔和橡皮只作用于当前图层。
  - 快捷键：Alt + 方向键切换模板 / 图层，Alt N 新模板，Alt K 克隆分叉，Alt L 新图层，Alt M 合并。
· 插件：时间画布、普通画布、二维模板画布、发帖子、导入阅读都改成了插件，在“设置 → 插件”里可以停用、卸载、安装新插件。
  插件停用后它的笔记不会丢，点开时可以一键重新启用。
· 插件开发包（压缩包里的“插件开发包”文件夹，或“设置 → 插件 → 插件开发指南”）：
  想要新画布时，把《插件开发指南.md》和你的需求一起交给 AI，它就知道插件该怎么写、要遵守什么。里面附一个可以直接安装的示例“康奈尔笔记画布”。
· 笔记库文件夹（左下角，替代原来的“一键导入导出”）：
  - 选一个文件夹（可以在网盘同步文件夹里或 U 盘上），全部笔记以普通文件放进去：每个侧边栏文件夹是一个子文件夹；PDF、电子书就是原文件，旁边同名的“….pdf.inknote”保存批注；手写笔记和帖子是“标题-编号.inknote”。
  - 把 PDF、电子书复制到某个子文件夹，会自动导入到侧边栏对应的文件夹；新建子文件夹，侧边栏就多一个文件夹。
  - 在资源管理器里移动、改名文件，笔记跟着变；在墨页里改名、移动、删除笔记，文件也跟着变（删除的文件移到回收站）。
  - 在文件夹里删了文件，墨页会先问你要不要也删掉笔记。
  - 换电脑：在新电脑上选同一个网盘文件夹（或复制过去的文件夹）即可。两边都改过的笔记另存一份“…（导入版本）”，不会丢内容。

0.6 的功能（带格式的文本框、Markdown 与 LaTeX 公式、帖子格式、1 GB 文件、受权限密码保护的 PDF 等）和 0.5.0 的功能（分屏、页面标题、连续滚动 / 单页翻页、可移动工具栏、两种橡皮擦、复制粘贴等）照常可用。
MOBI、AZW3 等格式仍需本机安装 Calibre；EPUB、TXT、PDF 等不需要。出版方 DRM 保护的文件无法读取。

系统：64 位 Windows 10 或 Windows 11。
此构建已完成自动化测试（包括在 Linux 版 Electron 45.2.3 中的启动、插件、二维模板画布和两台电脑共用一个笔记库文件夹的检查），尚未在 Windows 实机验证；安装向导只做过脚本语法检查。
