墨页 InkNote 0.6.1 · Windows 离线包

安装：解压压缩包后，双击 InkNote-Setup-0.6.1-offline.exe。
包内包含完整运行组件，安装无需联网。安装完成后从桌面“墨页 InkNote”打开。
从 0.3.x – 0.6.0 升级：直接运行新安装器，原有笔记会自动出现。

卸载：先保存并关闭墨页，再双击同文件夹的 Uninstall-InkNote.exe。
也可以在 Windows 设置 → 应用 → 已安装的应用 → 墨页 InkNote 中卸载。
笔记数据库、图片、电子书和笔记备份会保留。卸载也不需要联网。

0.6.1 的变化：
· 去掉了 Google 登录和云端硬盘同步，改为“一键导入导出”。
· 点左下角“一键导入导出”：第一次选一个文件夹（可以是 OneDrive、百度网盘等网盘的同步文件夹，或 U 盘）。
· “一键导出全部笔记”：每本笔记存成一个 .inknote 文件，没改动的自动跳过。
· “从文件夹一键导入”：新笔记加入，更新过的替换，不会重复；两边都改过的另存一份“…（导入版本）”。
· “选择文件导入…”：从网盘网页下载几个 .inknote 文件后，直接选中导入。

0.6 的其他功能：
· 新图标：Google 风格的蓝色笔尖和一笔红黄绿墨迹。
· 带格式的文本框（文字工具 T）：格式栏有标题、加粗、斜体、下划线、删除线、颜色、荧光、列表、引用、代码和公式。可以像 Markdown 一样直接打：行首“# ”变标题、“- ”变列表、“> ”变引用，$E=mc^2$ 变成排好的公式。拖动文本框顶部的横条移动，拖动右边缘调宽窄；Esc 或 Ctrl Enter 完成。
· 从网页、AI 对话、Word、OneNote 复制或拖进来的内容保留格式和公式。
· 把 .md 文件拖到页面上：Markdown 格式和 LaTeX 公式（$…$、$$…$$）直接排好版。
· 拖动复制：套索选中后按住 Ctrl 拖动，原处保留，拖出去的是副本。
· 帖子支持格式：主楼、楼层和楼中楼回复都支持 Markdown 和公式，输入框上方有格式按钮。
· 单个文件最大 1 GB（PDF、电子书、备份）。
· 设了权限密码（禁止打印、复制、修改）的 PDF 现在可以打开和批注；有打开密码的 PDF 会提示输入密码。出版方 DRM 保护的 PDF 和 EPUB 无法读取，会直接说明原因。
· MOBI、AZW3 等格式仍需本机安装 Calibre（体积大、许可不同，不适合内置）；EPUB、TXT、PDF 等不需要。

0.5.0 的功能（分屏、OneNote 式页面标题、连续滚动 / 单页翻页、可移动工具栏、两种橡皮擦、复制粘贴等）照常可用。

系统：64 位 Windows 10 或 Windows 11。
此构建已完成自动化测试（包括在 Linux 版 Electron 45.2.3 中的启动、分屏、保存、重启和两台电脑通过同一文件夹导入导出的检查），尚未在 Windows 实机验证。
