墨页 InkNote 0.5.0 · Windows 离线包

安装：解压压缩包后，双击 InkNote-Setup-0.5.0-offline.exe。
包内包含完整运行组件，安装无需联网。安装完成后从桌面“墨页 InkNote”打开。
从 0.3.x / 0.4.0 升级：直接运行新安装器，原有笔记会自动出现。

卸载：先保存并关闭墨页，再双击同文件夹的 Uninstall-InkNote.exe。
也可以在 Windows 设置 → 应用 → 已安装的应用 → 墨页 InkNote 中卸载。
笔记数据库、图片、电子书和笔记备份会保留。卸载也不需要联网。

本版新功能：
· 修复：右上角的关闭、最小化、最大化按钮在 Windows 上点了没反应（0.4.0 的问题，按钮被窗口拖动区域盖住了）。
· 翻页方式：「连续滚动」页面上下相连，像 PDF 阅读器一样一直滚下去，滚到哪页就在哪页写；「单页翻页」一次一页，滚到页面底部再滚动就翻到下一页。用页面右上角的按钮切换，设置里也能选。任何工具下滚轮都能翻页，包括拖动浏览（手形）。
· 工具栏可以移动：拖动书写工具栏左端的把手，放到页面的底部、顶部、左侧或右侧（左右两侧是竖排）；双击把手回到底部；设置里也能选。位置会记住。
· 分屏：笔记顶栏的分屏按钮（或 Ctrl \）可以在右侧打开另一本笔记，像浏览器的分屏标签页。两边各自编辑、各自保存；拖动中间的分隔条调整宽度，双击分隔条恢复一半；右侧顶栏可以左右交换或关闭分屏。分屏时整个窗口只有一个书写工具栏，左右两边共用同一支笔、颜色、粗细和橡皮擦模式。
· 页面标题：像 OneNote 一样，在页面顶部直接写标题，标题下面显示日期和时间。第 1 页的标题和笔记名称同步：改其中一个，另一个跟着改。缩略图下面也显示页面标题，可以双击缩略图重命名。
· 文字框：点击已有的文字会直接进入修改，不会再叠一个新的文字框；用套索或浏览工具时双击文字也能修改。清空文字后完成，就会删除这个文字框。
· 线距：横线、方格、点阵都有窄、标准、宽三种线距。新建笔记、添加页面和「纸张样式」里都可以选。
· 边距基准线：横线和方格纸默认在左侧有一条红色竖线，无限画布也有，可以在「纸张样式」里开关。
· 橡皮擦两种模式：「整笔」碰到就删除整条笔迹；「局部」只擦掉经过的部分。选中橡皮擦后再按 E 可以切换；橡皮擦大小可调，光标显示擦除范围。
· 复制粘贴：套索选中后可以 Ctrl C 复制、Ctrl X 剪切、Ctrl V 粘贴、Ctrl D 复制一份，Ctrl A 全选当前页；选中时页面下方会出现操作条。
· 其他：笔记库搜索现在会搜索页面标题、文字、批注和帖子内容并显示匹配片段；插入日期可以同时插入时间；页面可以上移、下移；新增「纸张样式」可以一次改全部页面。
· 修复：⋮ 菜单里的「重命名笔记」在旧版本中点保存后没有反应；新建画布对话框中「纸张范围」按钮显示错位。

旧笔记：原有页面没有标题栏，保持原来的样子，顶部仍然可以正常书写；需要时可以在 ⋮ 菜单里「重命名页面」补上标题。

系统：64 位 Windows 10 或 Windows 11。
此构建已完成自动化测试（包括在 Linux 版 Electron 45.2.3 中的启动、分屏、保存与重启检查），尚未在 Windows 实机验证。
