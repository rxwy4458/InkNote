# 墨页 InkNote 0.6.1

Windows 桌面笔记：PDF、时间画布、普通画布、电子书，以及一页一个帖子的楼中楼笔记。

0.6 增加带格式的文本框（Markdown 与 LaTeX 公式）、帖子格式、一键导入导出文件夹，换了新图标，单个文件上限提高到 1 GB，并能打开设了权限密码的 PDF。笔记数据、`.inknote` 备份与 0.3.x – 0.6.0 兼容。

0.6.1 去掉了 0.6.0 的 Google 登录与云端硬盘同步（需要每个用户自己在 Google Cloud 申请客户端 ID，太麻烦），改为「一键导入导出」：全部笔记导出到你选的文件夹，放进任何网盘或 U 盘，在另一台电脑一键导入。

## 安装

解压 `InkNote-Windows-0.6.1-offline.zip`，双击 `InkNote-Setup-0.6.1-offline.exe` 安装。压缩包同时附带独立的 `Uninstall-InkNote.exe`。安装器已包含应用、完整 Windows x64 桌面运行组件和卸载程序，安装过程没有下载代码，无需联网。

适用于 Windows 10 / 11 x64。安装后创建桌面和开始菜单快捷方式。程序安装在 `%LOCALAPPDATA%\Programs\InkNoteDesktop\InkNote-0.6.1`，笔记数据保存在 `%APPDATA%\InkNote`。从 0.3.x – 0.6.0 升级时直接运行新安装器即可：快捷方式和「已安装的应用」记录会指向新版本，原有笔记自动出现；旧版本程序目录会保留，卸载时一并清理。

运行组件取自 Electron 官方 v45.2.3 发布流水线的 `dist.zip` 构建产物。流水线产物的 SHA-256、内部运行组件 ZIP 的 SHA-256、平台、版本和应用文件已核对；来源与摘要保存在 `installer/runtime.json`。该流水线 ZIP 与经后续签名处理的公开发布 ZIP 是两个不同文件，摘要分别记录。

验证情况见 `VALIDATION.json`。**尚未在 Windows 实机上完成安装、启动与卸载验证。**

## 0.6 新功能

- **新图标**：Google 风格的蓝色笔尖，下面是一笔红黄绿的墨迹。窗口、任务栏、安装器和卸载器都用新图标；16 px 的小图标单独画了一版更粗的线条。
- **带格式的文本框**（文字工具 `T`）：
  - 选中文本框时上方有格式栏：正文 / 标题 1–3、加粗、斜体、下划线、删除线、文字颜色、荧光底色、项目符号、编号、引用、代码、公式、清除格式。`Ctrl B` / `Ctrl I` / `Ctrl U`。
  - 像 Markdown 一样直接打：行首 `# ` `## ` `### ` 变标题，`- ` `* ` 变项目符号，`1. ` 变编号，`> ` 变引用；`$E=mc^2$` 写完后变成排好的公式，`$$…$$` 是单独一行的公式。点击公式可以修改，带实时预览。
  - 文本框顶部的横条拖动可以移动，右边缘拖动调宽窄；`Esc` 或 `Ctrl Enter` 完成，点框外也完成。
  - 从网页、AI 对话、Word、OneNote 复制或拖进来的内容保留标题、加粗、颜色、列表、表格和公式（网页上的 KaTeX / MathJax 公式会还原成可编辑的公式）；脚本、外部图片和无法阅读的颜色（例如深色网页上的白字）会去掉。
  - **拖入 .md 文件**：松手的位置出现一个排好版的文本框，Markdown 格式和 `$…$` / `$$…$$` / `\(…\)` / `\[…\]` LaTeX 公式都会渲染；代码块里的 `$` 不当公式。.txt 和 .html 也可以拖进页面。其他文件仍按导入处理。
  - 文本框会出现在缩略图、导出的 PDF 和备份里，可以搜索。旧版的纯文字批注照常显示，点一下即升级为新文本框。
- **拖动复制**：套索选中后按住 `Ctrl`（或 `Alt`）拖动，原处保留，拖出去的是一份副本。复制的内容也会以纯文本和带格式文本放进系统剪贴板，可以粘贴到其他程序；从其他程序复制的文字粘贴到页面上会成为文本框。
- **帖子支持格式**：主楼、每一层楼和楼中楼回复都按 Markdown 显示（标题、加粗、列表、引用、代码、链接、公式）。发布框、新建帖子和编辑对话框上有一排格式按钮；从网页粘贴的带格式内容会自动转成 Markdown。旧帖子的纯文本照常显示。
- **一键导入导出**（左下角「一键导入导出」，或「设置 → 导入导出文件夹」）：
  - 第一次使用时选一个文件夹。可以选 OneDrive、百度网盘、Google 云端硬盘等网盘软件的同步文件夹，也可以是 U 盘或普通文件夹。
  - 「一键导出全部笔记」：每本笔记写成一个 `.inknote` 文件（文件名是笔记名加 8 位编号）。没改动的笔记跳过；改名后旧文件自动换成新名字；本机删除的笔记，导出时也会把它在文件夹里的文件移走。没改过的示例笔记不导出。
  - 「从文件夹一键导入」：读取文件夹里所有 `.inknote`。新笔记加入；同一本笔记有更新就替换，不会重复；本机已是最新的跳过；本机删除过的笔记不会被导回来。
  - 两台电脑都改过同一本笔记时，导入的那份另存为「…（导入版本）」，两份都在，不会丢内容。正在打开的笔记不会被替换。
  - 「选择文件导入…」：直接选一个或多个 `.inknote` 文件（或浏览器版导出的 `.zip`），同样按上面的规则合并。用来从网盘网页下载几个文件后导入。
  - 页面只把文件名交给主进程，只能读写所选文件夹里直接放着的 `.inknote` 文件。
  - 原来的「导入」按钮和单本「导出可编辑备份」保持不变（导入单个备份仍然是新建一份副本）。
- **单个文件最大 1 GB**：PDF、电子书和 `.inknote` 备份都可以到 1 GB。原始文件超过 48 MB 的备份改用 ZIP 容器（`inknote.json` + 原文件，逐项 CRC 校验），不再整体转成文本，导入导出都分块进行。旧的备份格式照常读取。
- **受保护的 PDF**：
  - 设了「权限密码」（禁止打印、复制、修改）的 PDF 现在可以直接打开、批注、搜索。
  - 设了「打开密码」的 PDF 会提示输入密码。
  - 导出时如果 PDF 允许批注或修改，会把每一页按高分辨率重新生成带批注的 PDF；如果作者禁止了修改和批注，导出会说明原因，笔记本身仍可正常使用和备份。
  - 出版商的版权保护（DRM，例如 Adobe ADEPT、Readium LCP、FileOpen）无法读取。PDF 和 EPUB 遇到这种情况会直接说明原因，而不是报一个看不懂的错误。墨页不会、也不能去除 DRM。
- **Calibre**：MOBI、AZW3 等格式仍然需要本机安装的 Calibre。Calibre 安装包约 150 MB，且是 GPL 许可，不适合打包进墨页；EPUB、TXT、PDF、FB2、HTML、CBZ、Markdown 不需要它。

## 0.5.0 新功能

- **修复窗口按钮**：0.4.0 中右上角的关闭、最小化、最大化按钮在 Windows 上点击没有反应。原因是按钮排在页面结构的最前面，后面的标题栏拖动区域又覆盖了它们；Electron 按文档顺序合并拖动区域，于是点击被当成拖动窗口。现在按钮放在最后，标题栏也不再延伸到按钮下面；已用真实的系统鼠标点击（X11 XTest）验证三个按钮。
- **翻页方式**（页面右上角按钮或「设置」）：
  - **连续滚动**（默认）：页面上下相连，像 PDF 阅读器。滚到哪一页，哪一页就是可书写的页面；在下一页露出的部分直接下笔也可以。
  - **单页翻页**：一次显示一页，滚到页面底部再滚动一下就翻到下一页，在顶部向上滚就回到上一页（停在它的底部）。
  - 两种方式在任何工具下都可用，包括拖动浏览（手形）工具。无限画布本身可以无限延伸，不参与翻页。
- **可移动的工具栏**：拖动书写工具栏左端的把手，放到页面的底部、顶部、左侧或右侧，左右两侧是竖排；双击把手回到底部，聚焦把手时可用方向键；「设置」里也可以选。位置会记住。
- **分屏**：笔记顶栏的分屏按钮（`Ctrl \`）在右侧打开另一本笔记，像浏览器的分屏标签页。
  - 两侧各自编辑、各自保存，同一本笔记不能同时在两侧打开。
  - 拖动中间的分隔条调整宽度（键盘可用方向键），双击恢复一半；宽度会记住。
  - 右侧顶栏可以「左右交换」或关闭分屏；返回笔记库或关闭窗口前，两侧都会先保存。
  - 整个窗口只有一个书写工具栏，浮在两侧之上，左右共用：选笔、颜色、粗细、橡皮擦模式，或在任一侧按快捷键，两边同时生效。这个工具栏同样可以拖到窗口的四边。
  - 两侧各自按自己的宽度排版：窄的时候顶栏会收紧，被收起的按钮可以在 ⋮ 菜单中找到。
- **OneNote 式页面标题**：页面顶部直接写标题，标题下面是一条细线和日期时间（时间画布）。
  - 第 1 页的标题和笔记名称同步，改其中一个，另一个跟着改；新建笔记时第 1 页标题就是笔记名称。
  - 缩略图下显示页面标题；双击缩略图或用 ⋮ 菜单「重命名页面」。
  - 标题画在纸上，所以也会出现在缩略图和导出的 PDF 里。
- **文字框**：点击已有文字直接修改，不会叠加新的文字框；套索或浏览工具下双击文字也能修改；清空后完成即删除。（0.6.0 起 Esc 是完成。）
- **线距**：横线、方格、点阵都有窄 / 标准 / 宽三种线距。
- **边距基准线**：横线和方格纸默认在左侧画一条红色竖线，A4 和无限画布都有，可以关闭。
- **纸张样式**（⋮ 菜单）：更换内页样式、线距和边距线，可以只改当前页或一次改全部页面，已有内容和标题不变。
- **橡皮擦**：「整笔」碰到就删除整条笔迹；「局部」只擦掉经过的部分，其余部分保留（矩形也可以局部擦除）。工具栏上切换，或选中橡皮擦后再按 `E`；大小 6–60 可调，光标显示擦除范围；模式会记住。
- **复制粘贴**：套索选中后 `Ctrl C` / `Ctrl X` / `Ctrl V` / `Ctrl D`（复制一份），`Ctrl A` 全选当前页；选中时页面下方出现操作条。可以跨页、跨笔记粘贴。
- **其他补充**：
  - 笔记库搜索现在搜索页面标题、文字、批注和帖子内容，并在卡片上显示匹配片段。
  - 插入日期时可以同时插入时间（北京时间）。
  - 页面可以上移 / 下移。
- **修复**：
  - ⋮ 菜单「重命名笔记」在 0.3.3 / 0.4.0 中点保存后没有反应（前一个对话框关闭事件误取消了新对话框）。
  - 0.4.0 新建画布对话框里「纸张范围」分段按钮显示错位。
  - 页面放大到比窗口宽时，左侧内容无法滚动到。
- **旧笔记**：0.5.0 之前的页面没有标题字段，保持原来的样子，顶部仍可正常书写；需要时用「重命名页面」补上标题。

## 界面与配色

- **Material You 风格**：大圆角、色调层次、胶囊导航，选中项会做形状变化；左上角有「新建」大按钮。首页有四个像快捷设置那样的新建磁贴：时间画布、普通画布、发帖子、导入阅读。
- **动态取色**：笔记库右上角的调色板按钮（或「设置」→「配色与外观」）可以选择配色：
  - 6 套预设：薰衣草、海湾蓝、薄荷绿、珊瑚橙、樱花粉、石墨灰。
  - 「自定义」：任选一个颜色作主色，整套界面配色由 Google 官方的 Material Color Utilities 自动生成。
  - 4 种配色风格：柔和、鲜明、表现力、中性。
  - 浅色、深色、跟随系统三种外观。
  - 选择后立即生效，并保存在本机。
- **页面与导出不受配色影响**：页面纸张始终为白色，深色模式下也一样，导出的 PDF 不受界面配色影响；时间画布的日期标签使用当前主色的浅色调。
- **画布**：书写工具放在底部的浮动工具栏，选中的工具会变成宽胶囊；页码和缩放在右上角。撤销/重做、仅用笔书写、插入日期、批注、查找和导出都在顶栏。双击标签可以重命名。
- **字体与图标**：图标使用 Material Symbols Rounded（89 个图标的子集），英文和数字使用 Google Sans Flex，中文使用系统的微软雅黑。字体和图标都随程序离线提供。

## 卸载

在 Windows 设置的「已安装的应用」中找到「墨页 InkNote」，点击卸载；也可以运行安装目录上一级的 `Uninstall-InkNote.exe`。卸载工具会要求先保存并关闭墨页，再清理已识别的 0.2.0 / 0.3.1 / 0.3.2 / 0.3.3 / 0.4.0 / 0.5.0 / 0.6.0 / 0.6.1 程序和快捷方式，移除本安装器创建的卸载记录。

笔记数据库、图片、电子书和 `.inknote` 备份会保留。目录链接不会被递归清理，程序目录里的文档、图片或少量许可文本可能留下。卸载工具自身也可能留在程序根目录，退出后可手动删除它。

之前单独提供的 `InkNote-Uninstall-Legacy.exe` 针对旧版 0.2 安装。本次压缩包中的 `Uninstall-InkNote.exe` 可独立从下载文件夹运行，也可以从 Windows「已安装的应用」卸载。

## 一页一个帖子

左侧「帖子与评论」是独立模块；首页和帖子列表都有「新建帖子」。

- 新建页面就是创建独立新帖：一个标题、一个主楼，自动带创建日期和时间。
- 同一帖子可连续发布 1 楼、2 楼、3 楼等独立楼层；点击「发新楼层」或底部发布框继续记录。
- 每层都可回复并继续回复。用逐级缩进、左侧细连接线和弯角表现真实父子关系，同级回复回到各自父级下面。保留 2.1、2.1.1 等位置编号与可点击的父级位置；发布框在发送前标明对应位置。每条自动记录日期和时间。
- 删除楼层不会重排其他楼号；旧版帖子打开时自动补全楼号，备份保留编号与回复关系。
- 主楼、楼层和回复都支持 Markdown 格式和公式（0.6.0 起），也都支持图片。正常阅读时固定为 76 × 76 的正方形缩略图，点击查看原图。
- 可搜索本帖正文、回复及图片名称；可以折叠回复、编辑、删除分支、撤销和重做。
- 文字、原图和楼中楼关系保存在本机，并包含在 `.inknote` 可编辑备份里。恢复帖子备份会保留原创建时间。

这类帖子与画布上的定位批注分别提供入口。画布仍可选批注工具 `C`，点击页面或选中笔迹插入楼中楼批注。

## 画布与阅读

| 类型 | 创建行为 | 分类 |
| --- | --- | --- |
| 时间画布 | 页面标题下自动标记创建日期和时间，新增页也自动标记 | 左侧「时间画布」 |
| 普通画布 | 无自动时间，可用「日期」按钮手动插入 | 左侧「普通画布」 |
| 帖子页面 | 标题、主楼及每层回复均带时间 | 左侧「帖子与评论」 |

时间/普通画布都可选择无限画布或固定 A4，以及空白、横线、方格、点阵和三种线距。无限画布从左上角向右、向下按需延伸，顶部与左侧有边界；只渲染当前视野。日期时间按北京时间显示。

支持 PDF 导入与笔迹、荧光笔、文字、矩形、套索、橡皮擦、书签、文本搜索和 PDF 导出。原始 PDF 文本继续可检索；旋转和裁切页面的批注坐标保留。无限画布按内容分成 A4 导出。

直接读取 EPUB、TXT、FB2、HTML、CBZ、Markdown（0.3.3 中这些格式的导入会报错 “raw is not defined”，0.4.0 已修复）；TXT 支持 UTF-8、UTF-16 和常见 GBK。MOBI、AZW、AZW3、LIT、PDB 等通过本机 Calibre 的 `ebook-convert.exe` 转换，需先安装 Calibre 并在「设置」中选择组件。单个文件最大 1 GB。带出版商 DRM 的文件无法读取，墨页不提供解除 DRM 的功能。

## 构建与验证

在带有 GNU gcc、binutils 和 Python 的 Linux 环境中，提供与 `installer/runtime.json` 对应的官方运行组件 ZIP，然后运行：

```sh
python3 installer/build-offline-exe.py --runtime runtime/electron-v45.2.3-win32-x64.zip
python3 installer/test-online-installer.py ../InkNote-Setup-0.6.1-offline.exe
python3 installer/build-uninstaller.py --current ../Uninstall-InkNote.exe
python3 installer/test-uninstaller.py
python3 scripts/make-icons.py      # 由 app/icon.svg 生成 icon.png / icon.ico
npm run check
npm test
```

输出为 `InkNote-Setup-0.6.1-offline.exe`。构建时若运行组件 SHA-256、平台或版本不匹配，会直接停止。安装器内部使用 Windows 自带 PowerShell 5.1 显示安装窗口并执行公开的 `installer/setup-offline.ps1`；安装器和卸载器入口均为 Windows GUI EXE。

`--startup-report` 启动检查只记录当前页面是否初始化成功，继续使用原有笔记目录；测试用 `--smoke-test-output` 会使用独立测试目录。结果通过临时文件写完后重命名，防止安装器读到尚未写完的 JSON。启动失败会尝试保存 `%APPDATA%\InkNote\logs\startup.log`。

也可在 Windows 构建另一种 NSIS 安装包：

```powershell
npm install --no-audit --no-fund
npm run dist:win
```

输出目标为 `release/InkNote-Setup-0.6.1-x64.exe`。附带 Windows Actions 工作流，构建后执行安装、启动与卸载检查。本次交付的完整离线 EXE 使用前述独立构建流程；不是 NSIS 产物。

本地界面检查使用 `npm run dev`（默认 http://127.0.0.1:43877/）。界面代码说明见 `界面重设计交接.md`。MIT 许可；第三方许可见 `THIRD_PARTY_NOTICES.md`。
